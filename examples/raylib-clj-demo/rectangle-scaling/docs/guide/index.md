# Rectangle Scaling

Drag to resize rectangle.

Category: shapes. Controls: Drag bottom-right corner.

Ported from raylib's `examples/shapes/shapes_rectangle_scaling.c`.

![rectangle-scaling](../demos/rectangle-scaling.gif)

## Run it

```sh
cd rectangle-scaling && bb run   # from this demo (or clojure -M:run)
bb rectangle-scaling             # from the repo root
```

## About

raylib [shapes] example - rectangle scaling

Drag the bottom-right corner of a rectangle to resize it.
Demonstrates mouse interaction and collision detection.

Difficulty: 2/4
Based on: shapes/shapes_rectangle_scaling.c
