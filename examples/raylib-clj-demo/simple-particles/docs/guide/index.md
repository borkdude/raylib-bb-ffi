# Simple Particles

Water/smoke/fire effects.

Category: shapes. Controls: Arrows, Click.

Ported from raylib's `examples/shapes/shapes_simple_particles.c`.

![simple-particles](../demos/simple-particles.gif)

## Run it

```sh
cd simple-particles && bb run   # from this demo (or clojure -M:run)
bb simple-particles             # from the repo root
```

## About

raylib [shapes] example - simple particles

Particle system with water, smoke, and fire effects.
Click to move emitter, arrow keys to change rate/type.

Difficulty: 2/4
Based on: shapes/shapes_simple_particles.c
