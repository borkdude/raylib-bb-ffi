# Following Eyes

Mouse tracking.

Category: core. Controls: Move mouse.

Ported from raylib's `examples/shapes/shapes_following_eyes.c`.

![following-eyes](../demos/following-eyes.gif)

## Run it

```sh
cd following-eyes && bb run   # from this demo (or clojure -M:run)
bb following-eyes             # from the repo root
```

## About

Raylib [shapes] example - following eyes

Two eyes that follow your mouse cursor around the screen.
Based on: raylib/examples/shapes/shapes_following_eyes.c

Complexity: ⭐⭐ Easy

Controls:
- Mouse: Move to make eyes follow
- F1: Toggle debug stats
- Q: Exit
