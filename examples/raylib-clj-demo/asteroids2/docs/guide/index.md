# Asteroids 2

Alternate version.

Category: games. Controls: Arrows, Space.

Written for this collection, not a port of a raylib example.

![asteroids2](../demos/asteroids2.gif)

## Run it

```sh
cd asteroids2 && bb run   # from this demo (or clojure -M:run)
bb asteroids2             # from the repo root
```

## About

Classic asteroids game - converted from raylib C example
Original: https://github.com/raysan5/raylib-games/blob/master/classics/src/asteroids.c
