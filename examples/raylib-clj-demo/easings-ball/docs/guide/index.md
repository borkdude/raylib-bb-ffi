# Easings Ball

Easing function animation.

Category: shapes. Controls: ENTER to replay.

Ported from raylib's `examples/shapes/shapes_easings_ball.c`.

![easings-ball](../demos/easings-ball.gif)

## Run it

```sh
cd easings-ball && bb run   # from this demo (or clojure -M:run)
bb easings-ball             # from the repo root
```

## About

raylib [shapes] example - easings ball

Ball animation using easing functions: elastic position,
elastic radius growth, and cubic alpha fade.

Difficulty: 2/4
Based on: shapes/shapes_easings_ball.c
