# Waving Cubes

Animated cube wave.

Category: models. Controls: Q to exit.

Ported from raylib's `examples/models/models_waving_cubes.c`.

![waving-cubes](../demos/waving-cubes.gif)

## Run it

```sh
cd waving-cubes && bb run   # from this demo (or clojure -M:run)
bb waving-cubes             # from the repo root
```

## About

Raylib [models] example - waving cubes

A mesmerizing 3D animation of cubes that wave and change colors based on their position.
The camera orbits around the scene automatically.
Based on: raylib/examples/models/models_waving_cubes.c

Complexity: ⭐⭐⭐ Intermediate (3/4)

Controls:
- Q: Exit
