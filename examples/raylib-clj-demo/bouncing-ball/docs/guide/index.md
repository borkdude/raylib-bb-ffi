# Bouncing Ball

Physics demo.

Category: core. Controls: SPACE, G.

Ported from raylib's `examples/shapes/shapes_bouncing_ball.c`.

![bouncing-ball](../demos/bouncing-ball.gif)

## Run it

```sh
cd bouncing-ball && bb run   # from this demo (or clojure -M:run)
bb bouncing-ball             # from the repo root
```

## About

Raylib [shapes] example - bouncing ball

A simple physics demo showing a ball bouncing with optional gravity.
Based on: raylib/examples/shapes/shapes_bouncing_ball.c

Complexity: ⭐ Beginner

Controls:
- SPACE: Pause/resume ball movement
- G: Toggle gravity on/off
- Q: Exit
