# Box Collisions

3D collision detection.

Category: models. Controls: Arrow keys, Q.

Ported from raylib's `examples/models/models_box_collisions.c`.

![box-collisions](../demos/box-collisions.gif)

## Run it

```sh
cd box-collisions && bb run   # from this demo (or clojure -M:run)
bb box-collisions             # from the repo root
```

## About

Raylib [models] example - box collisions

Move a player box around and detect collisions with other 3D objects.
The player turns red when colliding.
Based on: raylib/examples/models/models_box_collisions.c

Complexity: ⭐ Basic (1/4)

Controls:
- Arrow keys: Move player
- Q: Exit
