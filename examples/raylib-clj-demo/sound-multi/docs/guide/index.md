# Sound Multi

Multiple sounds.

Category: audio. Controls: SPACE.

Ported from raylib's `examples/audio/audio_sound_multi.c`.

![sound-multi](../demos/sound-multi.gif)

## Run it

```sh
cd sound-multi && bb run   # from this demo (or clojure -M:run)
bb sound-multi             # from the repo root
```

It loads `resources/sound.wav` by relative path, so run it from this directory. Those files carry their own terms: see `resources/LICENSE.md`.

## About

raylib [audio] example - sound multi

Playing multiple instances of the same sound using aliases.
