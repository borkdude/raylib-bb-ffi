# Screen Manager

State machine.

Category: core. Controls: ENTER.

Ported from raylib's `examples/core/core_basic_screen_manager.c`.

![screen-manager](../demos/screen-manager.gif)

## Run it

```sh
cd screen-manager && bb run   # from this demo (or clojure -M:run)
bb screen-manager             # from the repo root
```

## About

Raylib [core] example - basic screen manager

Demonstrates a simple state machine for managing game screens.
Based on: raylib/examples/core/core_basic_screen_manager.c

Complexity: ⭐ Beginner

Controls:
- ENTER: Navigate between screens
- Q: Exit (from any screen)
