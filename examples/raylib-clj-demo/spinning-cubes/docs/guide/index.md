# Spinning Cubes

Color-cycling cubes.

Category: models. Controls: Q to exit.

Written for this collection, not a port of a raylib example.

![spinning-cubes](../demos/spinning-cubes.gif)

## Run it

```sh
cd spinning-cubes && bb run   # from this demo (or clojure -M:run)
bb spinning-cubes             # from the repo root
```

## About

Raylib [models] example - spinning cubes

Multiple cubes spinning at different speeds and positions.
Demonstrates 3D transformations and color cycling.

Complexity: ⭐ Basic (1/4)

Controls:
- Q: Exit
