# Floppy

Flappy bird clone.

Category: games. Controls: SPACE, P, ENTER, Q.

Ported from `floppy.c` in [raysan5/raylib-games](https://github.com/raysan5/raylib-games).

![floppy](../demos/floppy.gif)

## Run it

```sh
cd floppy && bb run   # from this demo (or clojure -M:run)
bb floppy             # from the repo root
```

## About

Classic game: Floppy (Flappy Bird clone)

Original game by Ian Eito, Albert Martos and Ramon Santamaria.
Ported to Clojure for raylib-clojure-playground.

Complexity: ⭐⭐ (2/4)

Controls:
- SPACE: Fly up
- P: Pause game
- ENTER: Restart when game over
- Q: Exit
