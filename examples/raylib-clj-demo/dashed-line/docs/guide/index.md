# Dashed Line

Interactive dashed line.

Category: shapes. Controls: Arrows, C.

Ported from raylib's `examples/shapes/shapes_dashed_line.c`.

![dashed-line](../demos/dashed-line.gif)

## Run it

```sh
cd dashed-line && bb run   # from this demo (or clojure -M:run)
bb dashed-line             # from the repo root
```

## About

raylib [shapes] example - dashed line

Draw a dashed line that follows the mouse. Adjust dash
and space length with arrow keys, cycle color with C.

Difficulty: 1/4
Based on: shapes/shapes_dashed_line.c
