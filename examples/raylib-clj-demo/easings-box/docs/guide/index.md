# Easings Box

Box animation with easing functions.

Category: shapes. Controls: SPACE to reset.

Ported from raylib's `examples/shapes/shapes_easings_box.c`.

![easings-box](../demos/easings-box.gif)

## Run it

```sh
cd easings-box && bb run   # from this demo (or clojure -M:run)
bb easings-box             # from the repo root
```

## About

raylib [shapes] example - easings box

Box animation using different easing functions for each phase:
drop, flatten, rotate, expand, fade out.

Difficulty: 2/4
Based on: shapes/shapes_easings_box.c
