# Double Pendulum

Chaotic pendulum simulation.

Category: shapes. Controls: ESC to exit.

Ported from raylib's `examples/shapes/shapes_double_pendulum.c`.

![double-pendulum](../demos/double-pendulum.gif)

## Run it

```sh
cd double-pendulum && bb run   # from this demo (or clojure -M:run)
bb double-pendulum             # from the repo root
```

## About

raylib [shapes] example - double pendulum

Double pendulum physics simulation with trails rendered
to a framebuffer. Demonstrates chaotic motion.

Difficulty: 2/4
