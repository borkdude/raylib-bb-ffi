# Camera 2D

2D camera.

Category: core. Controls: Arrows, A/S, Wheel.

Ported from raylib's `examples/core/core_2d_camera.c`.

![camera-2d](../demos/camera-2d.gif)

## Run it

```sh
cd camera-2d && bb run   # from this demo (or clojure -M:run)
bb camera-2d             # from the repo root
```
