# Tetris

Block-stacking puzzle.

Category: games. Controls: Arrows, Space.

Written for this collection, not a port of a raylib example.

![tetris](../demos/tetris.gif)

## Run it

```sh
cd tetris && bb run   # from this demo (or clojure -M:run)
bb tetris             # from the repo root
```

## About

Classic tetris game - converted from raylib C example
Original: https://github.com/raysan5/raylib-games/blob/master/classics/src/tetris.c
Sample game developed by Marc Palau and Ramon Santamaria
