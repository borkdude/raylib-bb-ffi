# Writing Animation

Typewriter text effect.

Category: text. Controls: SPACE speed up, ENTER restart.

Ported from raylib's `examples/text/text_writing_anim.c`.

![writing-anim](../demos/writing-anim.gif)

## Run it

```sh
cd writing-anim && bb run   # from this demo (or clojure -M:run)
bb writing-anim             # from the repo root
```

## About

raylib [text] example - text writing animation

Shows a typewriter-style text animation effect.
Hold SPACE to speed up, press ENTER to restart.

Difficulty: 2/4
Based on: text/text_writing_anim.c
