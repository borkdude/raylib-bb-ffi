# Basic Shapes

Circles, rectangles, triangles, polygons.

Category: shapes. Controls: ESC to exit.

Ported from raylib's `examples/shapes/shapes_basic_shapes.c`.

![basic-shapes](../demos/basic-shapes.gif)

## Run it

```sh
cd basic-shapes && bb run   # from this demo (or clojure -M:run)
bb basic-shapes             # from the repo root
```

## About

raylib [shapes] example - basic shapes

Showcases all basic shape drawing functions available in raylib:
circles, rectangles, triangles, polygons, ellipses, and lines.
The polygon rotates continuously.

Difficulty: 1/4
Based on: shapes/shapes_basic_shapes.c
