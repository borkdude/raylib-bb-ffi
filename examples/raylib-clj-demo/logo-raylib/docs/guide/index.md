# Logo Raylib

Raylib logo drawn with shapes.

Category: shapes. Controls: ESC to exit.

Ported from raylib's `examples/shapes/shapes_logo_raylib.c`.

![logo-raylib](../demos/logo-raylib.gif)

## Run it

```sh
cd logo-raylib && bb run   # from this demo (or clojure -M:run)
bb logo-raylib             # from the repo root
```

## About

raylib [shapes] example - logo raylib

Draws the raylib logo using basic shapes (rectangles and text).
This is NOT a texture - it's drawn purely with shapes!

Difficulty: 1/4
Based on: shapes/shapes_logo_raylib.c
