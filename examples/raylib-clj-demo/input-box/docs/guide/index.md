# Input Box

Text input field.

Category: text. Controls: Click, type, Backspace.

Ported from raylib's `examples/text/text_input_box.c`.

![input-box](../demos/input-box.gif)

## Run it

```sh
cd input-box && bb run   # from this demo (or clojure -M:run)
bb input-box             # from the repo root
```

## About

raylib [text] example - input box

Type text into an input field. Click on the box to focus it,
type characters, and use backspace to delete.

Difficulty: 2/4
Based on: text/text_input_box.c
