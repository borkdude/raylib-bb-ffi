# First Person Maze

Navigate 3D maze.

Category: models. Controls: WASD, Mouse, R, M, Q.

Ported from raylib's `examples/models/models_first_person_maze.c`.

![first-person-maze](../demos/first-person-maze.gif)

## Run it

```sh
cd first-person-maze && bb run   # from this demo (or clojure -M:run)
bb first-person-maze             # from the repo root
```

## About

Raylib [models] example - first person maze

Navigate through a procedurally generated 3D maze.
Uses first-person camera with collision detection.

Complexity: ⭐⭐⭐ Intermediate (3/4)

Controls:
- WASD: Move
- Mouse: Look around
- R: Generate new maze
- M: Toggle minimap
- Q: Exit
