# Vampire Survivors

Survival action.

Category: games. Controls: WASD.

Written for this collection, not a port of a raylib example.

![vampire-survivors](../demos/vampire-survivors.gif)

## Run it

```sh
cd vampire-survivors && bb run   # from this demo (or clojure -M:run)
bb vampire-survivors             # from the repo root
```

## About

Vampire Survivors Clone - A top-down survival roguelike
Survive waves of enemies, auto-attack with weapons, collect XP, level up!
