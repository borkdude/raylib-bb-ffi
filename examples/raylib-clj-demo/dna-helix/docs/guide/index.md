# DNA Helix

Double helix.

Category: models. Controls: Arrows, SPACE, R, Q.

Written for this collection, not a port of a raylib example.

![dna-helix](../demos/dna-helix.gif)

## Run it

```sh
cd dna-helix && bb run   # from this demo (or clojure -M:run)
bb dna-helix             # from the repo root
```

## About

Raylib [models] example - DNA helix visualization

A 3D double helix structure visualization with animated rotation.
Demonstrates parametric 3D curves and sphere placement.

Complexity: ⭐⭐ Intermediate (2/4)

Controls:
- UP/DOWN: Adjust helix turns
- LEFT/RIGHT: Adjust helix radius
- SPACE: Toggle rotation
- R: Reset parameters
- Q: Exit
