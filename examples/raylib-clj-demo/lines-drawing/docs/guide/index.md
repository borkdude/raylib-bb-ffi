# Lines Drawing

Draw rainbow lines on canvas.

Category: shapes. Controls: Click, Right-click, Wheel, Middle.

Ported from raylib's `examples/shapes/shapes_lines_drawing.c`.

![lines-drawing](../demos/lines-drawing.gif)

## Run it

```sh
cd lines-drawing && bb run   # from this demo (or clojure -M:run)
bb lines-drawing             # from the repo root
```

## About

raylib [shapes] example - lines drawing

Draw on a canvas with the mouse. Left button draws rainbow lines,
right button erases. Mouse wheel adjusts thickness. Middle click clears.

Difficulty: 1/4
Based on: shapes/shapes_lines_drawing.c
