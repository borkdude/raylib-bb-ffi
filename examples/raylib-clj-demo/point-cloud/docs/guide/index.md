# Point Cloud

Spherical points.

Category: models. Controls: UP/DOWN, Q.

Ported from raylib's `examples/models/models_point_rendering.c`.

![point-cloud](../demos/point-cloud.gif)

## Run it

```sh
cd point-cloud && bb run   # from this demo (or clojure -M:run)
bb point-cloud             # from the repo root
```

## About

Raylib [models] example - point cloud

A colorful spherical point cloud visualization.
Points are distributed in a sphere with colors based on position.
Based on: raylib/examples/models/models_point_rendering.c (simplified)

Complexity: ⭐⭐ Intermediate (2/4)

Controls:
- UP/DOWN: Change point count
- Q: Exit
