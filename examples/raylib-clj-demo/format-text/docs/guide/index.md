# Format Text

Formatted score/timer display.

Category: text. Controls: ESC to exit.

Ported from raylib's `examples/text/text_format_text.c`.

![format-text](../demos/format-text.gif)

## Run it

```sh
cd format-text && bb run   # from this demo (or clojure -M:run)
bb format-text             # from the repo root
```

## About

raylib [text] example - text formatting

Displays formatted text: score, hi-score, lives, and
real-time frame time using Clojure's format function.

Difficulty: 1/4
Based on: text/text_format_text.c
