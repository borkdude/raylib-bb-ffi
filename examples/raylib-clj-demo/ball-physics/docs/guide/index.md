# Ball Physics

Grab and throw balls.

Category: shapes. Controls: Click, Right-click, Wheel, Middle.

Ported from raylib's `examples/shapes/shapes_ball_physics.c`.

![ball-physics](../demos/ball-physics.gif)

## Run it

```sh
cd ball-physics && bb run   # from this demo (or clojure -M:run)
bb ball-physics             # from the repo root
```

## About

raylib [shapes] example - ball physics

Grab and throw balls with the mouse. Right-click to spawn
new balls. Scroll to change gravity. Middle-click to shake.

Difficulty: 2/4
Based on: shapes/shapes_ball_physics.c
