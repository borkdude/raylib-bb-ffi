# Mouse Trail

Circles following mouse cursor.

Category: shapes. Controls: Move mouse.

Ported from raylib's `examples/shapes/shapes_mouse_trail.c`.

![mouse-trail](../demos/mouse-trail.gif)

## Run it

```sh
cd mouse-trail && bb run   # from this demo (or clojure -M:run)
bb mouse-trail             # from the repo root
```

## About

raylib [shapes] example - mouse trail

Draws a trail of circles following the mouse cursor.
Older positions fade out and shrink.

Difficulty: 1/4
Based on: shapes/shapes_mouse_trail.c
