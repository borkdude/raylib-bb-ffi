# Wireframe Shapes

Custom wireframes.

Category: models. Controls: SPACE, Q.

Written for this collection, not a port of a raylib example.

![wireframe-shapes](../demos/wireframe-shapes.gif)

## Run it

```sh
cd wireframe-shapes && bb run   # from this demo (or clojure -M:run)
bb wireframe-shapes             # from the repo root
```

## About

Raylib [models] example - wireframe shapes

Various 3D wireframe shapes drawn using lines.
Demonstrates draw-line-3d! for custom wireframe rendering.

Complexity: ⭐⭐ Intermediate (2/4)

Controls:
- SPACE: Toggle rotation
- Q: Exit
