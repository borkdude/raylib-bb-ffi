# Input Keys

Keyboard input.

Category: core. Controls: Arrow keys.

Ported from raylib's `examples/core/core_input_keys.c`.

![input-keys](../demos/input-keys.gif)

## Run it

```sh
cd input-keys && bb run   # from this demo (or clojure -M:run)
bb input-keys             # from the repo root
```

## About

Raylib [core] example - keyboard input

Move a ball around the screen using arrow keys.
Based on: raylib/examples/core/core_input_keys.c

Complexity: ⭐ Beginner

Controls:
- Arrow keys: Move the ball
- F1: Toggle debug stats
- Q: Exit
