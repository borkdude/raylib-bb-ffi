# Retro Maze 3D

GameBoy-style maze escape.

Category: games. Controls: WASD, Mouse, SPACE, M, ENTER, Q.

Ported from `retro_maze_3d.c` in [raysan5/raylib-games](https://github.com/raysan5/raylib-games).

![retro-maze-3d](../demos/retro-maze-3d.gif)

## Run it

```sh
cd retro-maze-3d && bb run   # from this demo (or clojure -M:run)
bb retro-maze-3d             # from the repo root
```

## About

Retro Maze 3D - A GameBoy-style first-person maze game

Based on raylib's GGJ 2021 game by Ramon Santamaria.
Ported to Clojure with procedural maze generation.

Complexity: ⭐⭐⭐ (3/4)

Controls:
- WASD: Move
- Mouse: Look around
- SPACE: Pause menu
- M: Toggle minimap
- ENTER: Select/Continue
- Q: Exit
