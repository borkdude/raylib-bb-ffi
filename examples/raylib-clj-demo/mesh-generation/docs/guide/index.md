# Mesh Generation

Procedural 3D shapes.

Category: models. Controls: Left/Right, Click, SPACE, R, Q.

Ported from raylib's `examples/models/models_mesh_generation.c`.

![mesh-generation](../demos/mesh-generation.gif)

## Run it

```sh
cd mesh-generation && bb run   # from this demo (or clojure -M:run)
bb mesh-generation             # from the repo root
```

## About

Raylib [models] example - procedural mesh/shape generation

Showcase of procedurally generated 3D shapes.
Demonstrates various geometric primitives and custom shapes.

Based on raylib's models_mesh_generation example.

Complexity: ⭐⭐ (2/4)

Controls:
- LEFT/RIGHT or Click: Cycle through shapes
- SPACE: Toggle wireframe
- R: Toggle rotation
- Q: Exit
