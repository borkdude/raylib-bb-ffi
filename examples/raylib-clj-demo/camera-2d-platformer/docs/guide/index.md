# Camera 2D Platformer

5 camera follow modes.

Category: core. Controls: Arrows, SPACE, C, R, Wheel.

Ported from raylib's `examples/core/core_2d_camera_platformer.c`.

![camera-2d-platformer](../demos/camera-2d-platformer.gif)

## Run it

```sh
cd camera-2d-platformer && bb run   # from this demo (or clojure -M:run)
bb camera-2d-platformer             # from the repo root
```

## About

raylib [core] example - 2D camera platformer

A simple platformer with 5 different camera follow modes.
Press C to cycle through camera modes, R to reset,
mouse wheel to zoom.

Difficulty: 3/4
Based on: core/core_2d_camera_platformer.c
