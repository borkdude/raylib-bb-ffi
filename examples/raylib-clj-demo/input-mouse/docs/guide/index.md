# Input Mouse

Mouse input.

Category: core. Controls: Click, move.

Ported from raylib's `examples/core/core_input_mouse.c`.

![input-mouse](../demos/input-mouse.gif)

## Run it

```sh
cd input-mouse && bb run   # from this demo (or clojure -M:run)
bb input-mouse             # from the repo root
```

## About

Raylib [core] example - mouse input

A ball that follows your mouse. Click to change colors!
Based on: raylib/examples/core/core_input_mouse.c

Complexity: ⭐ Beginner

Controls:
- Mouse: Move the ball
- Left click: Red color
- Right click: Blue color
- Middle click: Green color
- F1: Toggle debug stats
- Q: Exit
