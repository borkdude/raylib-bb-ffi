# Tesseract View

4D hypercube.

Category: models. Controls: Q to exit.

Ported from raylib's `examples/models/models_tesseract_view.c`.

![tesseract-view](../demos/tesseract-view.gif)

## Run it

```sh
cd tesseract-view && bb run   # from this demo (or clojure -M:run)
bb tesseract-view             # from the repo root
```

## About

Raylib [models] example - tesseract view

Visualize a tesseract (4D hypercube) projected into 3D space.
The tesseract rotates in 4D and is then projected to 3D for rendering.
Based on: raylib/examples/models/models_tesseract_view.c

Complexity: ⭐⭐ Intermediate (2/4)

Controls:
- Q: Exit
